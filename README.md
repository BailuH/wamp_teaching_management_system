# 教务管理系统

基于 WAMP（Windows + Apache + MySQL + PHP）开发的简易教务管理系统，对**学生、教师、课程、选课成绩**四类信息进行增删改查，并提供成绩统计与重算功能。支持**学生登录**查看个人信息，以及**超级管理员**进入后台管理。为中国政法大学《数据库管理实验》课程作业。

## 功能

### 学生端（普通用户）

- **登录认证**：通过学号 + 密码登录（密码明文存储于 `user` 表，仅作演示）。
- **个人信息**：查看本人基本信息（姓名、性别、出生日期、贷款金额、平均成绩）。
- **选课成绩查询**：查看本人所有选课及成绩，未录入成绩显示“尚未录入”。
- **退出登录**：一键销毁会话返回登录页。

### 管理端（超级管理员）

- **学生管理**：录入、查询（按学号/姓名模糊搜索）、编辑、删除学生信息（含性别、出生日期、贷款金额）。
- **教师管理**：维护教师工号、姓名、性别、职称、院系。
- **课程管理**：维护课程编号、课程名、任课教师（外键关联教师表）。
- **选课成绩**：为学生选课并录入/修改成绩，支持按学生或课程筛选。
- **成绩统计**：按学生、按课程汇总选课人数、平均分、最高/最低分；可一键重算所有学生的 `average_grade` 字段。

### 通用特性

- **PRG 模式**：管理端写操作成功后跳转，避免刷新重复提交；提示信息通过 URL `msg` 参数传递。
- **安全防护**：使用 mysqli 预处理语句防 SQL 注入；输出统一经 `htmlspecialchars` 转义防 XSS。
- **会话管理**：学生端使用 PHP `$_SESSION` 守卫，`student.php` 未登录访问自动跳回登录页。

## 技术栈

| 层    | 技术                                  |

## 目录结构

```
hwq/
├── login.html            学生登录页（前端表单）
├── login.php             学生登录验证脚本（查 user 表）
├── student.php           学生个人页（基本信息 + 选课成绩，session 守卫）
├── logout.php            退出登录（销毁 session）
├── admin_login.php       超级管理员登录页（硬编码演示账号）
├── hwq.html              管理端首页 / 学生录入表单
├── style.css             全局样式
├── xsgl.sql              数据库结构与初始数据导出
├── includes/
│   ├── db.php            数据库连接 + 公共辅助函数（h、redirect_with_msg）
│   └── layout.php        页面头部/尾部/导航栏渲染函数
├── add_*.php             各实体“新增”处理脚本
├── list_*.php            各实体“列表 + 搜索”展示页
├── edit_*.php            各实体“编辑”页面（GET 展示表单 / POST 更新）
├── delete_*.php          各实体“删除确认 + 执行”页面
└── stats.php             成绩统计与平均分重算
```

数据库表：

| 表     | 含义     | 主键          | 主要字段                                  |
| ------ | -------- | ------------- | ----------------------------------------- |
| `xs`   | 学生     | `xh`(学号)     | xm, xb, csrq, loan_price, average_grade   |
| `js`   | 教师     | `gh`(工号)     | xm, xb, zc, yx                            |
| `kc`   | 课程     | `kcbh`(课程号) | kcm, rkjs(任课教师→js.gh)                  |
| `xk`   | 选课     | (xh, kcbh)     | cj(成绩)                                  |
| `user` | 登录账号 | `username`     | password（明文，关联 xs.xh）              |

> 含外键级联删除（`ON DELETE CASCADE`）：删学生/课程时其选课记录自动清理；删学生时对应 `user` 账号也自动删除。

## 快速开始

### 1. 环境准备

安装 WAMP（Windows）/ XAMPP / 任意 LAMP 套件，确保 Apache + MySQL + PHP 已启动。

### 2. 导入数据库

打开 phpMyAdmin 或 MySQL 命令行，导入 `xsgl.sql`：

```bash
mysql -u root -p < xsgl.sql
```

该脚本会创建 `xsgl` 数据库及五张表，并写入示例数据。

### 3. 部署代码

将整个 `hwq/` 目录复制到 Web 根目录：

- WAMP：`C:\wamp64\www\hwq`
- XAMPP：`C:\xampp\htdocs\hwq`

如数据库账号非默认的 `root` 空密码，请编辑 `includes/db.php` 第 4 行：

```php
$conn = new mysqli('localhost', '用户名', '密码', 'xsgl');
```

### 4. 访问

- **学生入口**：<http://localhost/hwq/login.html>
- **超级管理员入口**：在学生登录页底部点“超级管理员入口 →”，或直接访问 <http://localhost/hwq/admin_login.php>

## 使用说明

### 学生端

1. 在 `login.html` 输入学号和密码（如 `0324101` / `123456`）登录。
2. 登录后进入 `student.php`，可查看基本信息和选课成绩。
3. 点“退出登录”返回登录页。

### 管理端

1. 在 `login.html` 底部点“超级管理员入口 →”进入 `admin_login.php`。
2. 用 `admin` / `admin123` 登录后跳转到 `hwq.html` 管理首页。
3. 学生列表页顶部支持按学号或姓名搜索；每行有“编辑 / 选课 / 删除”三个操作。
4. 录入成绩：在选课成绩页或学生列表点“选课”，选择学生和课程，填入成绩（可留空表示尚未录入）。
5. 成绩统计页：可按学生、按课程查看汇总指标，点击“重算所有学生平均成绩”会将 `xk` 表的平均值写回 `xs.average_grade`。
